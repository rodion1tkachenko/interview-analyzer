# Помощник по собеседованиям: требования

Статус: уточняем требования с владельцем. Реализацию ещё не начинаем.
План обсуждения и будущие задачи: [tasks.md](tasks.md).

## Согласовано

Это дипломный проект для личного использования владельцем. Он загружает
запись собственного собеседования длительностью примерно час, получает
разбор и готовится к следующим собеседованиям. Главная польза — увидеть
слабые места в своих ответах.

- Специальность фиксирована: Java-разработчик.
- Владелец проходит собеседования на middle–senior. Выбор уровня вакансии
  и отдельные режимы оценки по уровням не нужны. Критерии оценки ещё обсудим.
- Запись переводится в текст, затем языковая модель выделяет вопросы,
  ответы кандидата и анализирует ответы.
- Разбор каждого вопроса содержит:
  1. Что спросили.
  2. Что ответил кандидат, с указанием времени в записи.
  3. Что правильно, что неправильно и чего не хватило.
  4. Оценку с объяснением.
- Вместо развёрнутого примера хорошего ответа нужно указать, что почитать.
  Формат ещё обсудим: темы, названия материалов или конкретные ссылки.
- Название компании можно запрашивать при загрузке; обязательность
  этого поля пока не согласована.
- Требования обсуждаем небольшими группами вопросов и фиксируем в текущем
  PR. Реализацию начинаем по указанию владельца.

## Отложено

В текущий план первой версии не входят:

- Топ вопросов, в том числе частотность между собеседованиями.
- Похожие тренировочные вопросы.
- Развёрнутые примеры хороших ответов.

## Предложения по качеству — ещё обсуждаем

- Связывать выводы с фрагментами расшифровки, не придумывать ответы.
- Допускать отсутствие оценки при неразборчивой речи и недостатке данных.
- Различать ошибку распознавания и ошибку кандидата.
- Сверить выделение вопросов и оценки с ручным разбором записей.
- Измерить скорость и стоимость на часовой записи.

## Что уже есть в репозитории

По чтению кода, без проверки запуском: Java/Spring Boot API загрузки
и статусов, PostgreSQL и Liquibase, извлечение аудио через FFmpeg,
Python/FastAPI с faster-whisper для русской речи и временных меток,
сохранение расшифровки и ошибок. Есть сущности интервью и вопросов,
тесты Java и конфигурация CI.

Анализ ответов, разделение говорящих и пользовательский интерфейс
в просмотренном коде не реализованы. Обработка часового файла требует
проверки. Поля в сущностях не означают готовность функции.
